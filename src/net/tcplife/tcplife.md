# tcplife 诊断指南

## 概述

`tcplife` 在连接关闭时输出该连接的完整生命周期总结。它记录了连接存活的总时间、传输的数据量（RX/TX 字节数）以及连接双方的详细信息。

**核心场景**：

1. **业务流审计**：统计短连接与长连接的占比及其数据特征。
2. **连接泄漏排查**：识别那些长时间存活但几乎没有任何数据交互的“僵死连接”。
3. **资源计量**：评估某个特定业务应用在一段时间内产生的真实网络总负荷。

## 命令行参数

| 参数 | 缩写 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `--pid`       | `-p` | uint32 | 0 | 仅统计指定 PID 的连接寿命 |
| `--timestamp` | `-T` | bool | false | 在输出中包含时间戳 |
| `--ipv4`      | `-4` | bool | false | 仅审计 IPv4 连接 |
| `--ipv6`      | `-6` | bool | false | 仅审计 IPv6 连接 |
| `--wide`      | `-w` | bool | false | 宽列输出（适配 IPv6 展示） |
| `--localport` | `-L` | string | "" | 逗号分隔的本地端口列表过滤 |
| `--remoteport`| `-D` | string | "" | 逗号分隔的远程端口列表过滤 |
| `--verbose`   | -    | bool | false | 打印调试详细信息 |

## AI 逻辑与调用指引

### 何时调用

AI Agent 在观测到以下需求时，应考虑调用此工具：

- **资源优化分析**: AI 需要分析系统中哪些进程开启了过多浪费资源的长连接。
- **故障后审计**: 当大批连接异常断开时，AI 调用 `tcplife` 总结断开时刻的流量、寿命特征以寻找共性规律。
- **非法流量特征分析**: 识别那些寿命极短但频率极高的连接模式（可能是爬虫或漏洞扫描）。

### 输出解读 (AI 视角)

- **MS (存活时间)**: 区分瞬间连接（几毫秒）和成熟的长连接（几分钟/小时）。
- **TX_KB / RX_KB**: 连接在其整个生命周期内搬运的数据量总和。AI 应识别出那些吞吐异常巨大的连接。

## 与相关工具的关系

- **与 tcptop 的关联**: `tcptop` 关注即时吞吐，`tcplife` 关注历史汇总。
- **诊断闭环**: 使用 `tcptracer` 观察连接开启，使用 `tcpstates` 观察中间变化，最后使用 `tcplife` 生成本次生命周期的终结报告。
