基于当前ksight项目，你需要在当前文件夹下，实现一个非特权级别的网络工具，非特权级的意思是不使用eBPF，可以在不打开BPF工具的内核上运行。可以使用root权限，也可以不使用root权限。

它的调用级别：1级（最常用调用级别），后续开发agent在碰到问题时，会优先调用这个工具来排查问题。

你需要作为一个专业的经验丰富的网络工程师，来设计这个工具。
你需要兼顾2个方面，第一个是通用场景的网络部分，第二个是面向低延迟，注重实时性，而对带宽部分不那么敏感的场景。例如汽车内部的网络通信。
但你关心的指标，依然是通用的。协议栈相关的。例如车载场景下的如SOME/IP、DDS等等，这一块会有另外的工具来处理，在当前的工具中，不需要处理。

例如，网络部分，可能有以下几个方面需要关注：
1. 带宽
2. 吞吐
3. 延迟
4. 抖动
5. 丢包

可以使用命令，也可以从/proc、/sys等路径读取信息来获取这些信息。

你还可以参考一下ref/catpaw/plugins下面跟网络有关的哪些工具。

目前计划使用Python3来开发这个工具，保证它可以在Python3.8及以上的版本运行。
